# 팀 요청·답변·결정 작성 양식

사용자가 지정한 필수 양식. 앞으로 팀원에게 보낼 요청사항을 작성할 때 적용한다. 문안 작성은 외부 문서 입력·카톡 등 실제 전송 승인이 아니다.

## 배치와 기록 규칙

- 요청·질문: 받는 사람 탭 › 보내는 사람 하위 탭. 예: C가 B에게 → To B › C→B.
- 전체 알림: To 전체 › 보내는 사람 하위 탭.
- 답변: 기존 요청 블록 안에 이어 쓴다. 새 탭/별도 요청으로 만들지 않는다.
- 새 요청은 하위 탭 맨 위에 추가한다.
- 요청·답변·결정 모두 `10/07 09:30` 형식으로 시간을 표시한다. 작성 시간은 Asia/Seoul 기준으로 확인한다. 기존 요청 시간은 유지한다.
- 확정된 결정은 요약 탭 맨 아래 ✅ 결정 기록에 한 줄 옮긴다. 제안을 합의된 결정으로 표시하지 않는다.
- 🔴 급한 요청은 카톡으로 번호만 알리는 팀 규칙이다. 실제 카톡 발송은 별도 사용자 승인이 필요하다.
- 번호는 보낸사람+받는사람+번호. 예: C→B는 CB-03. 기존 번호를 알면 이어 쓰고 모르면 번호 미확정으로 표시한다. 필요 시점이 주어지지 않으면 미정으로 표시한다.
